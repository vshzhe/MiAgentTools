# 模块与功能点

> 生成时间：2026-10-10 | 扫描范围：CodeGraph 索引（69 源文件 / 1003 符号节点）+ 源码结构

## 架构总览

项目采用"模板层 → 生成层 → 命令层"三层架构，参考 OpenSpec 设计：

```text
src/core/templates/workflows/    模板层：技能内容（中文正文）
        │
src/core/command-generation/     生成层：格式化 + 路径解析 + 适配器
        │
src/cli/index.ts + commands/     命令层：iagent CLI（11 个命令）
```

## 模块分解

### 1. CLI 入口（`src/cli/index.ts`）

Commander.js 程序组装：`buildProgram()` 注册全部 11 个命令并暴露 `runCli()`。

### 2. 命令实现（`src/commands/`）

| 文件 | 命令 | 职责 |
|:---|:---|:---|
| `init.ts` | `iagent init` | 生成全部技能与指令到 `.claude/`，预扫描、权限合并、依赖检测 |
| `list.ts` | `iagent list` | 列出已安装技能（按类型分组），`--json` 结构化输出 |
| `validate.ts` | `iagent validate` | 校验 frontmatter 完整性（name/description/allowed-tools/type） |
| `update.ts` | `iagent update` | 升级技能到内置模板最新版（内容指纹手改保护） |
| `generate.ts` | `iagent generate` | 按类型生成新技能骨架 → `skills/` 源文件 + `.claude/` 安装 |
| `uninstall.ts` | `iagent uninstall` | 移除 iagent 技能与指令（dry-run 预览 + 安全边界） |
| `show.ts` | `iagent show` | 查看技能详情（frontmatter/类型/白名单/正文），模糊匹配 |
| `completion.ts` | `iagent completion` | bash/pwsh 补全脚本生成与安装 |
| `onboarding.ts` | （引导提示） | `iagent init` 后的下一步使用引导 |
| `spec.ts` | `iagent spec` | 规格驱动工作流子命令组（new/status/instructions/archive） |
| `config.ts` | `iagent config` | 交互式设置 workflows 列表（`--set` / `--show`） |

### 3. 模板层（`src/core/templates/`）

#### 3.1 技能模板（`workflows/`）

9 类技能类型，每类含多个技能模板：

| 类型 | 模板文件 | 内置技能 |
|:---|:---|:---|
| `init` | `project-init.ts` | `iagent_project_init` |
| `impl` | `workflow.ts`、`auto-workflow.ts`、`debug.ts`、`proposal-review.ts`、`migration.ts`、`migration-check.ts` | `iagent_workflow` 等 6 个 |
| `test` | `test.ts` | `iagent_test` |
| `commit` | `commit.ts` + `svn-commit.ts` | `iagent_commit`、`iagent_svn_commit` |
| `review` | `review.ts` | `iagent_review` |
| `release` | —（保留类型，无内置技能） | — |
| `tools` | —（保留类型，无内置技能） | — |
| `docs` | `feature-doc.ts` + `requirement-doc.ts` | `iagent_feature_doc` 等 |
| `spec` | `spec-*.ts`（7 个） | `iagent_spec_explore` 等 |

#### 3.2 模板支撑

| 文件 | 职责 |
|:---|:---|
| `types.ts` | `SkillTemplate` / `CommandTemplate` 接口定义 |
| `registry.ts` | 模板注册表、`deriveCommandId` 派生规则、指令白名单回填 |
| `tool-whitelist.ts` | 白名单共享常量（CodeGraph MCP 双写 / 派发条目 / 委派条目） |
| `derive-command.ts` | spec 模板 command 压缩版派生（CMD:SKIP 标记裁剪） |
| `prompt-gate.ts` | 提示门控逻辑（阻断点判定） |
| `flowchart-gate.ts` | 流程图门控（阶段推进判定） |
| `index.ts` | 模板层统一导出 |

### 4. 生成层（`src/core/command-generation/`）

| 文件 | 职责 |
|:---|:---|
| `generator.ts` | `generateSkillContent()` / `generateCommand()` —— 模板 → 产物 |
| `fingerprint.ts` | 产物内容指纹计算（手改保护判定信号） |
| `yaml.ts` | `escapeYamlValue()` / `formatTagsArray()` —— YAML 转义 |
| `types.ts` | `ToolCommandAdapter` 接口（多工具扩展点） |
| `adapters/claude.ts` | Claude Code 适配器（路径规则 + frontmatter 格式） |
| `adapters/registry.ts` | 适配器注册表 |
| `index.ts` | 生成层统一导出 |

### 5. 规格驱动工作流（`src/core/spec/`）

| 文件 | 职责 |
|:---|:---|
| `schema.ts` | 变更制品 schema 定义（proposal/specs/design/tasks） |
| `status.ts` | 变更状态查询（当前阶段判定） |
| `archive.ts` | 变更归档逻辑 |
| `instructions.ts` | 制品模板定义（PROPOSAL/SPECS/DESIGN/TASKS） |
| `new-change.ts` | 新变更创建 |
| `sqlite-index.ts` | SQLite 索引后端（变更元数据持久化） |
| `sqlite-memory-backend.ts` | SQLite 内存后端（sql.js WASM） |
| `sidecar-schema.ts` | 附属文件 schema |
| `templates/index.ts` | 规格模板导出 |

### 6. 配置与权限（`src/core/`）

| 文件 | 职责 |
|:---|:---|
| `config.ts` | 常量中心：`SKILL_PREFIX`、9 类 `SKILL_TYPES`、`AI_TOOLS` |
| `project-config.ts` | `.iagent/config.yaml` 读写（context / rules / workflows 解析） |
| `permissions.ts` | 会话级权限载体（`.claude/settings.json` 的 `permissions.allow` 非破坏合并） |
| `project-scan.ts` | 项目预扫描（`.iagent/scan-baseline.json` 生成） |
| `profiles.ts` | workflow 默认集与依赖注入（DEPS） |
| `dependencies.ts` | 依赖检测（codegraph CLI + MCP 注册） |
| `reconcile.ts` | 孤立产物协调（workflows 配置变更后的废弃产物检测） |

### 7. 工具层（`src/utils/`）

| 文件 | 职责 |
|:---|:---|
| `file-system.ts` | 文件读写、目录遍历、路径解析等基础操作 |

## 技能生命周期体系

```text
init → impl → test → commit → review → release
  │                                                    │
  ├── tools（横切工具）                              │
  ├── docs（文档生成，横切）                          │
  └── spec（规格驱动工作流，独立闭环）                    │
```
