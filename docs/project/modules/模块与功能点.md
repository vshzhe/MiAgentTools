## 1. 模块地图

项目采用「模板层 → 生成层 → 命令层」三层架构（参考 OpenSpec）：

```text
src/core/templates/workflows/    模板层：20 个技能正文（唯一源）
        │
src/core/command-generation/     生成层：frontmatter / 指纹 / 适配器
        │
src/cli/index.ts + commands/     命令层：13 个 iagent CLI 命令
```

## 4. 模块间交互

- **CLI → 命令**：`src/cli/index.ts:22-44` 直接 import 各命令入口；`spec` / `rules` / `skills` / `version` 以 `addCommand` 挂载（`src/cli/index.ts:442-447`）。
- **模板 → 生成**：`registry.ts:11-69` 引入工作流模板；`generator.ts:14-19` 依赖 `fingerprint` / `skill-id` / `yaml`。
- **适配器 → 落点单源**：各适配器统一经 `command-artifacts.ts` 取路径（`adapters/claude.ts:10`）。
- **无循环依赖**：`config.ts` 为叶子常量；`skill-id.ts:14-17` 只依赖 `config` 以避免循环导入。
- **Markdown-first 数据流**：`openspec/changes/**` Markdown → `spec/parser` → `model/artifact-model` → `validation` / `status` / `archive`。
