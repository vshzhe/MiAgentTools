# 安全规范

> 生成时间：2026-10-10 | 扫描范围：`src/` 全量 + `.iagent/config.yaml` + `.claude/settings.json`

> ⚠️ 本文件定位为**机制与约定说明**，不写入凭据值、不写入可利用的绕过细节。

## 概述

MiAgentTools 为**本地 CLI 工具**，运行于开发者本机，无服务端暴露面。安全关注点集中在：技能权限白名单、输入校验、配置管理。

## 认证机制

**不适用。** 本工具为本地命令行程序，无用户登录态、无会话令牌、无 SSO 集成。

## 鉴权机制

### 技能级权限白名单

Claude Code 加载技能时，按 SKILL.md frontmatter 的 `allowed-tools` 字段限制该技能可调用的工具。这是**声明式、逐技能枚举**的授权模型：

- 每份 `SKILL.md` 的 frontmatter 包含 `allowed-tools` 字段，列出该技能可使用的工具
- Claude Code 运行时按白名单拦截：技能只能调用其 frontmatter 中声明的工具
- 白名单缺失的产物会在 `iagent validate` 中被标记为 CRITICAL

**白名单三层结构**（`src/core/templates/tool-whitelist.ts`）：

| 层 | 内容 | 约束 |
|:---|:---|:---|
| 只读检索 | Read / Glob / Grep | 按正文实际使用，不无差别补齐 |
| 调用类 | CodeGraph MCP、Skill(iagent_xxx)、Agent/Task | MCP 双写（裸服务器 + 具名工具），委派逐技能枚举 |
| 技能专有 | Bash(...) / Write / Edit | 只增不减维持现状，MUST NOT 扩大 |

### 会话级权限载体

技能 frontmatter 授权仅覆盖调用当轮。跨轮次管线需要会话级放行：

- `iagent init` / `iagent update` 将本工具集条目**非破坏合并**进 `.claude/settings.json` 的 `permissions.allow`
- 实现位于 `src/core/permissions.ts`：不删既有条目、不碰 `deny` 段、过滤 `Bash(*)` 通配符、非法 JSON 保留原文件、幂等

## 输入校验策略

| 校验位置 | 方式 | 覆盖 |
|:---|:---|:---|
| CLI 参数 | Commander.js choices / requiredOption | 类型名（9 类之一）、工具名（claude）、shell 名（bash/powershell） |
| 技能名 | 正则校验（kebab-case） | `iagent generate --name` 非法字符直接报错 |
| 文件名 | 前缀校验（iagent_） | `iagent validate` 检测技能目录名不符合前缀规范 |
| YAML | `escapeYamlValue()` | frontmatter 值中含冒号/引号时转义（`src/core/command-generation/yaml.ts`） |
| 路径 | Windows 归一化（`replaceAll('\\', '/')`） | 路径断言跨平台兼容 |
| JSON | 结构校验 + 保留原文件 | `permissions.ts` 中 settings.json 非法 JSON 不覆盖 |

## 配置约定

### 配置项类别与键名

| 文件 | 键名 | 说明 |
|:---|:---|:---|
| `.iagent/config.yaml` | `context` | 项目背景（多行文本，供技能生成注入） |
| `.iagent/config.yaml` | `rules` | 引用的规则类型列表（如 impl、test） |
| `.iagent/config.yaml` | `workflows` | 用户选择的 workflow id 列表 |
| `.iagent/config.yaml` | `tools` | 目标 AI 工具列表（claude / pi / codex） |
| `.claude/settings.json` | `permissions.allow` | 会话级工具白名单（字符串数组） |

### 凭据

本工具**不涉及凭据**——不读写口令、密钥、令牌、连接串。生成的所有配置文件中仅含键名与结构，不含取值。

## 依赖安全

- `iagent init` 自动检测并安装 codegraph CLI（`npm install -g @colbymchenry/codegraph`）和 openspec CLI（`npm install -g @fission-ai/openspec`）
- 安装失败仅输出警告与手动命令，**不阻断主流程**
- `--no-deps` 可跳过整个依赖步骤
