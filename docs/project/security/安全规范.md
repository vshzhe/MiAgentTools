# 安全规范

> 生成时间：2026-11-09 | 扫描范围：`src/` 全量 + `.iagent/config.yaml` + `.claude/settings.json` 读取逻辑

> ⚠️ 本文件定位为**机制与约定说明**，不写入凭据值、不写入可利用的绕过细节。

## 概述

MiAgentTools 为**本地 CLI 工具**，运行于开发者本机，无服务端监听、无对外网络接口。安全关注点集中在：技能权限白名单、会话级权限载体、输入校验、配置文件保真写入与子进程参数处理。

## 认证机制

**不适用。** 本工具为本地命令行程序，无用户登录态、无会话令牌、无 SSO 集成。`src/` 全量检索未发现认证中间件或令牌处理逻辑。

## 鉴权机制

### 技能级权限白名单（声明式、逐技能）

每个 SKILL.md 的 frontmatter `allowed-tools` 限定该技能可调用的工具；缺失会在 `iagent validate` 中被判为异常（`src/commands/validate.ts:140`）。

白名单按三层组合（共享常量单一源 `src/core/templates/tool-whitelist.ts`）：

| 层 | 内容 | 约束 | 证据 |
|:---|:---|:---|:---|
| 只读检索 | `Read` / `Glob` / `Grep` | 按正文实际使用，不无差别补齐 | `tool-whitelist.ts:28-93` |
| 调用类 | CodeGraph MCP 双写 / CodeGraph CLI / 精确委派 / 派发双写 | MCP 与 CLI 两套命名互不覆盖；委派逐技能枚举，禁用 `Skill(*)` | `tool-whitelist.ts:28/44/52/93` |
| 技能专有 | `Bash(...)` / `Write` / `Edit` | 只增不减，MUST NOT 扩大 | `src/core/templates/types.ts:64-72` |

- 斜杠指令的白名单与配对技能完全一致：由 `getCommandTemplates()` 单点回填（`src/core/templates/registry.ts:167-171`），不另立第二份真源。
- 技能 ID 白名单只认 canonical 形态 `Skill(iagent-<workflowId>)`；裸名下划线与无前缀形态均为死条目（`src/core/skill-id.ts:29/51`）。

### 会话级权限载体

技能 frontmatter 授权仅覆盖调用当轮，跨轮次管线需会话级放行：

- `iagent init` / `iagent update` 把本工具集条目**非破坏合并**进 `.claude/settings.json` 的 `permissions.allow`（`src/core/permissions.ts:90`）。
- 合并规则：不删既有条目（`permissions.ts:139-156`）、不碰 `deny` / `ask` 段（`permissions.ts:156`）、过滤全量放行条目 `Bash(*)` 与裸 `*`（`permissions.ts:23`）、非法 JSON 保留原文件（`permissions.ts:145`）、幂等（同名条目已存在不重复追加）。
- OpenCode 不使用该载体：权限走项目级 `.opencode/opencode.jsonc` 的 V2 `permissions` 段。

## 输入校验策略

| 校验位置 | 方式 | 落点（文件:行） |
|:---|:---|:---|
| CLI 选项 | Commander `choices` / `requiredOption` | `src/cli/index.ts:396-399`（generate 必填 `--type` / `--name`） |
| 技能名 | kebab-case 正则 `^[a-z0-9]+(-[a-z0-9]+)*$` | `src/commands/generate.ts:48`，失败抛错 `:109-110` |
| 技能类型 | `SKILL_TYPES` 成员校验 | `src/core/config.ts:36`（9 类） |
| YAML frontmatter | 含冒号 / 引号的值经 `escapeYamlValue` 转义 | `src/core/command-generation/yaml.ts:9` |
| 配置写入 | 逐行段替换，保留注释、未知段与人工域 | `src/core/project-config.ts:1032`；人工域破损取保留侧 `:523-560` |
| 权限 JSON | 结构校验；非法 JSON 不覆盖原文件 | `src/core/permissions.ts:139-156` |
| 子进程参数 | cmd.exe 引号规则转义（`quoteArgumentForCmd`） | `src/core/child-process.ts:52`（调用点 `:87`） |
| 扫描忽略规则 | 解析失败按 fail-open（该文件不生效并记警告） | `src/core/scan-ignore.ts:18-21/261` |
| 技能产物完整性 | 缺章节 / 空章节 / 占位符 / 无证据规则 / name 不匹配 | `src/core/project-skills.ts:219` |

- 路径断言跨平台归一化为正斜杠；`path.join` 不硬编码分隔符。
- 删除类操作有安全边界：`iagent uninstall` 先 dry-run 预览（`src/commands/uninstall.ts:54`）；指令产物删除只认 `iagent-` 前缀或本工具命名空间（`src/core/command-artifacts.ts:126`）；非 iagent 技能不碰。

## 配置约定

### 配置项类别与键名（只记录键名）

| 文件 | 键名 | 说明 |
|:---|:---|:---|
| `.iagent/config.yaml` | `context` | 项目背景（多行文本，注入技能生成） |
| `.iagent/config.yaml` | `rules` | 引用的规则类型列表（如 `impl` / `test` / `spec`） |
| `.iagent/config.yaml` | `workflows` | 生效 workflow id 列表 |
| `.iagent/config.yaml` | `tools` | 目标 AI 工具（`claude` / `pi` / `codex` / `opencode`） |
| `.iagent/config.yaml` | `skills` | 项目技能分组（`frontend` / `backend`）与条目 |
| `.iagent/config.yaml` | `compileCheck` | 编译检查门（`enabled` / `command` / `timeoutMs` / `incremental` / `autoFix` / `maxRetries`） |
| `.iagent/rules/*.md` | 人工域标记 | `<!-- 人工域:开始 -->` / `<!-- 人工域:结束 -->` 区间由自动更新逐字保留 |
| `.iagent/scan-baseline.json` | `version` / `signals` / `limits` / `failures` | 预扫描基线 v2 |
| `.claude/settings.json` | `permissions.allow` | 会话级工具白名单（字符串数组） |
| `.opencode/opencode.jsonc` | `permissions` | OpenCode V2 动作（`skill` / `subagent`） |

- `.iagent/config.yaml` 回写 MUST 走逐行段替换，MUST NOT 重新序列化 YAML（`src/core/project-config.ts:1032`）。
- 本工具**不涉及凭据**：不读写口令、密钥、令牌或连接串；生成配置仅含键名与结构。

## 依赖安全

- `iagent init` 自动检测并安装两个外部 CLI：codegraph（`@colbymchenry/codegraph`）与 openspec（`@fission-ai/openspec`）（`src/core/dependencies.ts:111`）。
- 安装失败仅输出警告与手动命令，**不阻断主流程**；`--no-deps` 跳过整个依赖步骤。
- 已存在依赖时跳过，不主动升级覆盖。
- Pi 运行时默认尝试项目级安装 `@tintinweb/pi-subagents`，失败落 `degraded` + `.iagent/pi-runtime.json` 诊断，不阻断（`src/core/pi-runtime.ts:395`）。
