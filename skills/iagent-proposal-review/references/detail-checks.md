## Phase 5: 特殊功能场景检查

**针对特殊功能场景，必须执行此阶段检查。**

### 5.1 导出功能检查（6 项）

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **导出SQL正确性** | 导出SQL与列表SQL条件一致 | 导出数据与页面不一致 |
| **大数据量导出** | 分批导出或限制导出条数 | 内存溢出或超时 |
| **导出字段完整性** | 导出列与显示列一致 | 遗漏关键字段 |
| **文件名规范** | 文件名包含日期时间戳 | 文件名冲突 |
| **编码格式** | Excel/CSV使用UTF-8编码 | 中文乱码 |
| **敏感数据脱敏** | 导出数据是否需要脱敏 | 数据泄露风险 |

### 5.2 导入功能检查（6 项）

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **文件格式校验** | 校验Excel/CSV格式 | 格式错误导致解析失败 |
| **模板一致性** | 导入模板与解析逻辑对应 | 列位置错误 |
| **必填字段校验** | 导入数据必填字段非空 | 空数据入库 |
| **数据唯一性校验** | 导入前检查编码唯一性 | 重复数据导入 |
| **导入失败处理** | 记录失败行号和原因 | 用户无法定位问题 |
| **导入进度反馈** | 大批量导入显示进度 | 用户无感知等待 |

### 5.3 外部系统回调检查（4 项）

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **回调签名验证** | 验证回调来源合法性 | 伪造回调攻击 |
| **回调幂等处理** | 同一回调多次处理不重复 | 重复执行操作 |
| **回调超时处理** | 回调处理失败的重试机制 | 操作丢失 |
| **回调日志记录** | 记录回调内容和处理结果 | 无法追溯 |

### 5.4 并发安全检查（4 项）

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **静态变量并发** | 静态Map/List的线程安全 | 并发数据错误 |
| **缓存并发更新** | 多线程更新缓存的同步 | 缓存不一致 |
| **计数器并发** | 统计计数器的原子操作 | 计数不准确 |
| **数据库并发** | 同一记录并发更新的锁机制 | 数据覆盖丢失 |

### 5.5 搜索条件处理检查（4 项）

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **特殊字符转义** | LIKE查询的 `%` `_` 需要转义 | 搜索结果错误 |
| **SQL注入防护** | 搜索参数过滤或参数化 | SQL注入风险 |
| **空搜索条件** | 无条件时的默认排序 | 排序不稳定 |
| **多条件组合** | 多搜索条件的AND/OR逻辑 | 条件组合错误 |

## Phase 6: 页面设计细节检查

**针对涉及前端页面的变更，必须执行此阶段检查。**（前端检查见「语言 / 框架专项检查」小节 F）

### 6.1 页面结构完整性检查

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **基础引入** | 页面开头引入项目基础初始化文件 | 缺少基础初始化 |
| **表单状态** | 表单页面引入状态保存文件 | 状态保存缺失 |
| **DOCTYPE声明** | HTML标准 DOCTYPE 声明 | 声明缺失或错误 |
| **meta标签** | charset、浏览器兼容模式设置 | 兼容模式未设置 |
| **CSS引入位置** | head标签内，按顺序引入 | 引入顺序错误导致样式覆盖 |

### 6.2 表单元素完整性检查

| 元素类型 | 检查项 | 常见遗漏 |
|---------|-------|---------|
| **form标签** | name、id、action、method属性完整 | 缺少id导致JS无法操作 |
| **隐藏字段** | 分页参数、搜索条件回传字段 | 分页参数缺失 |
| **输入框** | name、id、value回显、maxlength | maxlength与数据库字段长度不一致 |
| **下拉框** | 默认值设置、空值选项、回显处理 | 编辑页面缺少选中状态处理 |
| **文本域** | rows、cols、maxlength设置 | 无长度限制导致数据库截断 |
| **单选/复选框** | 默认选中状态、disabled状态处理 | 编辑页面选中状态未恢复 |
| **文件上传** | enctype、文件类型限制 | 缺少类型校验 |

### 6.3 数据绑定正确性检查

| 绑定方式 | 检查项 | 常见错误 |
|---------|-------|---------|
| **列表数据绑定** | id、name、scope属性正确 | name与request.setAttribute不一致 |
| **行数据绑定** | 嵌套结构正确 | 缺少嵌套导致数据无法获取 |
| **字段获取** | 列名/字段名大小写符合项目规范 | 大小写不匹配导致获取失败 |
| **EL表达式** | 仅用于非表单元素 | hidden字段不应使用EL（会被覆盖） |
| **行序号获取** | 使用计数变量而非不存在的getRowIndex() | 调用不存在的方法 |

### 6.4 分页标签完整性检查

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **分页组件位置** | 必须在 form 标签内 | 位置错误导致分页失效 |
| **分页URL** | 入口层 URL 与方法参数对应 | method 参数格式 |
| **分页参数** | 与入口层参数名一致 | pageNum、pageSize |
| **搜索条件保持** | 分页组件后添加搜索条件保持标签 | 缺少导致搜索条件丢失 |
| **总记录数** | 后端设置总记录数属性 | 后端未设置导致显示0 |

### 6.5 JavaScript逻辑完整性检查

| 功能类型 | 检查项 | 常见遗漏 |
|---------|-------|---------|
| **表单提交** | form.submit() 而非仅设置action | 缺少submit调用 |
| **搜索刷新** | document.getElementById("searchForm").submit() | 使用错误的form引用 |
| **弹出窗口** | 弹窗组件参数完整性 | 缺少title、width、height |
| **树形控件** | 树控件初始化、onClick回调 | 回调函数未定义 |
| **下拉框** | 下拉组件初始化、change事件 | 值变化后未触发联动 |
| **日期选择** | 日期组件初始化、format格式 | format与数据库不一致 |
| **表格组件** | 表格组件配置、列定义 | 列名与数据字段不匹配 |

### 6.6 CSS样式一致性检查

| 检查项 | 规范要求 | 常见问题 |
|-------|---------|---------|
| **类名使用** | 使用项目定义的CSS类 | 自定义类名不一致 |
| **表格样式** | 项目标准表格样式类 | 缺少边框导致视觉混乱 |
| **按钮样式** | 项目标准按钮样式类 | 样式类名错误 |
| **表单样式** | 项目标准表单样式类 | 样式不统一 |
| **响应式** | 项目栅格布局类 | 固定宽度导致布局问题 |
| **浏览器兼容** | 按项目声明的浏览器兼容级别，避免不支持的语法 / 布局 | 兼容级别不符导致页面异常 |

### 6.7 前端组件使用规范检查

| 组件 | 规范检查点 | 常见错误 |
|-----|----------|---------|
| **项目实际组件库** | 从既有页面提取组件清单：引入路径、初始化参数、版本一致性 | 引入路径错误、版本不一致、缺少必要资源 |

## Phase 7: 逻辑实现细节检查

**针对业务逻辑实现，必须执行此阶段检查。**

### 7.1 业务逻辑完整性检查

| 检查维度 | 具体检查项 | 常见遗漏 |
|---------|----------|---------|
| **CRUD完整性** | 新增、查询、修改、删除四个操作是否完整 | 修改功能遗漏 |
| **状态流转** | 状态字段的所有可能值是否都有处理逻辑 | 状态值遗漏处理 |
| **关联数据处理** | 主数据操作时关联数据是否同步处理 | 删除主数据时关联数据未删除 |
| **序号生成** | 主键/序号生成方式符合项目实际（序列 / 自增 / UUID 等） | 取值方式错误（如误用当前值而非下一个值） |
| **编码生成** | 编码唯一性校验、生成规则 | 编码重复未校验 |
| **预置数据** | 预置数据是否禁止删除/修改 | 系统预置数据被误删 |

### 7.2 数据一致性检查

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **主从数据一致性** | 删除主数据时删除关联从数据 | 外键约束导致删除失败 |
| **状态同步** | 状态变更时同步更新关联状态 | 状态不一致 |
| **缓存同步** | 数据变更时刷新缓存 | 缓存与数据库不一致 |
| **计数同步** | 关联数量变化时更新统计字段 | 统计数据不准确 |
| **时间同步** | 创建/修改时间自动设置 | modifytime未更新 |

### 7.3 编辑场景特殊检查

| 检查项 | 规范要求 | 常见遗漏（高频） |
|-------|---------|----------------|
| **旧数据清理** | 编辑保存前必须删除旧配置 | **数据累积而非替换** |
| **回显数据获取** | 编辑页面必须查询并回显现有数据 | 字段值未回显 |
| **编码不可修改** | 编码字段在编辑模式下应禁用 | 编码被修改导致关联断裂 |
| **预置数据保护** | 预置数据禁止编辑 | 系统预置数据被误改 |
| **状态保持** | 编辑不应改变未修改的状态 | 状态意外变化 |

### 7.4 缓存处理检查

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **缓存刷新时机** | 数据变更后立即刷新缓存 | 缓存与数据库不一致 |
| **缓存键定义** | 缓存键格式一致、含义明确 | 键格式混乱 |
| **缓存失效** | 设置合理的过期时间或手动失效 | 缓存永不过期 |
| **缓存穿透** | 查询空结果时设置空缓存 | 大量查询打到数据库 |
| **并发缓存** | 缓存更新时的并发安全 | 缓存更新冲突 |

### 7.5 定时任务检查

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **任务配置** | 时间参数可配置 | 硬编码时间 |
| **任务日志** | 开始、结束、耗时日志完整 | 缺少执行日志 |
| **异常处理** | 异常捕获后不影响下次执行 | 异常导致任务停止 |
| **并发控制** | 防止同一任务并发执行 | 多实例并发问题 |
| **状态记录** | 记录任务执行状态和结果 | 无法追踪执行情况 |

### 7.6 批量操作检查

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **分批处理** | 大批量数据分批提交（每批100-500条） | 一次性提交过多 |
| **事务控制** | 批量操作的事务范围合理 | 事务过大或过小 |
| **失败处理** | 批量失败时的部分成功处理 | 全部失败或忽略 |
| **进度反馈** | 长时间批量操作的进度提示 | 用户无感知 |
| **结果统计** | 批量操作的成功/失败计数 | 结果不明确 |

### 7.7 权限控制细节检查

| 检查项 | 规范要求 | 常见遗漏 |
|-------|---------|---------|
| **页面权限** | 页面级权限检查包含请求上下文参数 | 缺少请求参数 |
| **操作权限** | 新增、修改、删除分别检查权限 | 仅检查页面权限 |
| **数据权限** | 查询时过滤用户可见数据范围 | 越权查看数据 |
| **按钮权限** | 功能按钮按权限显示/隐藏 | 无权限用户可见按钮 |
| **API权限** | REST API的权限校验 | API无权限校验 |
